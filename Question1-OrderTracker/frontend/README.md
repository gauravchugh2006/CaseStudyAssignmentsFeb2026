# Question 1 - Frontend (React + TypeScript)

## Run locally (Windows + VS Code)
1. Install **Node.js 20+**.
2. Open terminal in `Question1-OrderTracker/frontend`.
3. Install deps and run:
   ```bash
   npm install
   npm run dev
   ```
4. Open `http://localhost:4173`.
5. Set API URL if needed:
   - PowerShell: `$env:VITE_API_URL="http://localhost:5000"`

## Build
```bash
npm run build
```
